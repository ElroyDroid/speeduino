Speeduino custom v29.4 - AVR STL guard patch

Functional ECU behaviour is unchanged from v29.

The latest build confirmed:
- the local avr-libstdcpp headers are now being found correctly;
- compilation fails because those headers themselves emit
  '#error "avr-libstdcpp requires avr-gcc 8 or newer"'.

v29.4 keeps the working local include-path setup from v29.3 and changes the
pre-build script so that AFTER the headers exist (downloaded or cached), it
scans them and removes only that exact GCC8 version guard.

Expected build output:
avr-libstdcpp: using cached local copy at ...
avr-libstdcpp: GCC7 guard patched in N header(s)

PlatformIO Mega2560 toolchain remains avr-gcc 7.3.0.

Build:
1. Extract into a fresh folder.
2. PlatformIO Clean.
3. Build megaatmega2560.

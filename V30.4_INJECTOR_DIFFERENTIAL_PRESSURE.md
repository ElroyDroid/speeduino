# Speeduino custom v30.4 - injector differential-pressure compensation

Adds optional injector differential-pressure compensation to the existing v30.3 custom branch.

## Features
- Computes injector differential pressure from fuel rail gauge pressure + barometric pressure - MAP.
- Optional injector flow correction: `sqrt(reference delta-P / actual delta-P)`.
- Optional 6x6 pressure x voltage injector dead-time table with bilinear interpolation.
- Uses the existing 50 unused bytes on config page 15 (no page-size increase).
- Existing fueling behaviour is unchanged after upgrade because both new corrections default OFF.
- Table defaults are Bosch 0 280 158 117 published data, sampled at 2.5/3.0/3.5/4.0/5.0/6.0 bar and 10/11/12/13/14/16 V.
- Default reference pressure is 4.0 bar to be close to the current 1.7 ms half-ReqFuel tune; verify before enabling.

## Important test notes
1. Verify the existing fuel-pressure sensor calibration first.
2. Burn the tune with both new corrections OFF and confirm behaviour is identical to v30.3.
3. Enable flow correction only and log.
4. Then enable pressure/voltage dead-time compensation and log again.
5. Do not enable if the fuel-pressure sensor is faulty or not enabled. Firmware falls back to legacy behaviour when the sensor feature is disabled or rail pressure reads below 5 psi.

## Storage
Offsets 206-255 of page 15 are used exactly; page remains 256 bytes.

Dead-time source: https://finjector.com/documents/66f53e9192229/0280158117_Data.pdf


## Rated injector flow display option
- Page 15 byte 206 bits 2-7 now store injector rated flow in 25 cc/min steps (0-1575 cc/min).
- Default is 550 cc/min for Bosch 0280158117.
- TunerStudio shows **Injector flow at reference pressure** and calculates **Effective Injector Flow** from current differential pressure.
- Effective flow is informational; the actual pulse-width correction remains the physically correct sqrt(reference delta-P / actual delta-P) ratio, so no extra flow table is required.
- For Bosch 0280158117 use 550 cc/min at 3.0 bar if Required Fuel is based on the nominal injector rating.

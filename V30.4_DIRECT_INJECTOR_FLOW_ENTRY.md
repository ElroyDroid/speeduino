# v30.4 direct injector-flow entry update

This revision keeps the injector differential-pressure feature within the same 50 bytes on page 15.

- Byte 206 bit 0: flow correction enable
- Byte 206 bit 1: pressure/voltage dead-time enable
- Byte 206 bits 2-7: reference differential pressure, 0.1 bar steps, 0-6.3 bar
- Byte 207: rated injector flow in 25 cc/min steps, directly editable in TunerStudio (25-6375 cc/min)
- Bytes 208-255: unchanged 6x6 pressure/voltage dead-time calibration

Data version is 41. The v40->v41 migration preserves the v40 pressure reference and rated flow settings while swapping their packed locations.

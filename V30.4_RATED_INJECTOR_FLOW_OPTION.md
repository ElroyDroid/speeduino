# v30.4 rated injector flow option

This update adds an injector-flow-at-reference-pressure setting without increasing page 15 size.

- Storage: page 15 byte 206 bits 2-7 (previously unused), 25 cc/min per step.
- Range: Not set, then 25 to 1575 cc/min.
- Default for Bosch 0 280 158 117: 550 cc/min.
- Flow reference differential pressure remains the existing `injPressureRef` setting.
- TunerStudio calculates live effective injector flow as:

  effectiveFlow = ratedFlow * sqrt(actualDifferentialPressure / referenceDifferentialPressure)

- The actual fuel pulse-width correction remains:

  pwMultiplier = sqrt(referenceDifferentialPressure / actualDifferentialPressure)

The rated-flow value is diagnostic/informational and does not apply a second fueling correction.

For Bosch 0 280 158 117 nominal data use 550 cc/min at 3.0 bar if Required Fuel is based on the nominal injector rating.

EEPROM data version is bumped from 39 to 40. Existing v39 pressure reference, enable flags and dead-time table are preserved; only the newly-used rated-flow bits are initialised to 550 cc/min.

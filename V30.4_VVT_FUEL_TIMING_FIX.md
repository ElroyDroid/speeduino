# v30.4 VVT fuel timing fix

The existing **Adjust fuel timing** setting (`vvtCLAlterFuelTiming`) is now functional for closed-loop VVT1.

## Behaviour

When all of the following are true:
- VVT1 enabled
- VVT mode = Closed Loop
- Adjust fuel timing = Yes
- measured VVT1 angle is valid

Speeduino adjusts the injector **end-of-injection** angle using the measured cam advance:

`corrected EOI = base injector EOI - measured VVT1 advance`

`currentStatus.vvt1.angle` is stored in 0.5 crank-degree units, so it is divided by two before being applied to the whole-degree injector angle table.

Example: base EOI 350 deg, measured VVT advance 20 deg => corrected EOI 330 deg.

The result wraps over the configured injector-angle cycle (normally 720 deg for sequential four-stroke injection).

## Failsafe

If the VVT angle-error flag is active, no VVT fuel timing correction is applied; the normal injector angle table is used.

## Compatibility

With **Adjust fuel timing = No**, injector timing is unchanged from the previous v30.4 build. The pressure-dependent injector flow/dead-time feature is unchanged.

## Tests added

Unit tests cover:
- switch disabled => no change
- +20 deg measured advance => 350 deg becomes 330 deg
- VVT angle error => fallback to base timing
- crank-angle wrap-around

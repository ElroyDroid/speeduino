# v30.5 Haltech-style dashpot / A/C catch

This revision changes the closed-loop PWM idle dashpot without adding EEPROM bytes.

## New options
- **Hold full dashpot until catch RPM** (page 15 byte 181 bit 1): when enabled, dashpot time decay does not start at throttle closure. Full dashpot is retained while RPM is above `Idle Target + Full Dashpot Above Target`. The decay clock starts when RPM enters that catch region.
- **Extra A/C catch using Idle Up amount** (page 15 byte 181 bit 2): when enabled and the existing Idle Up input is active (the A/C relay signal on this installation), the configured `Idle Up Amount` is added a second time only during the active dashpot event. The extra amount follows the same RPM/time taper and therefore disappears before settled idle.

Example: normal dashpot = 10%, Idle Up Amount = 5%. With A/C relay active, the maximum transient catch becomes 15%, while the steady A/C idle-up remains +5%.

The feature is modelled on Haltech's separation of steady A/C Base Offset from Decel Offset / Throttle Follower catch behaviour.

## Compatibility
EEPROM data version 42. Existing v30.4/v41 tunes migrate with both new options OFF, preserving previous behaviour until explicitly enabled. Page 15 size is unchanged.
